# Reference series (not used by the model)

Downloaded source series not currently used by the model. Kept as possible benchmarks and cross-checks (e.g. HIV deaths and new infections, reported malaria cases and deaths, TB treatment coverage). Source, indicator code and download date for each:

Download date: the download itself was not recorded; each file was added to the repo on 2026-10-07 (commit history), so it was downloaded on or before that date. No script downloads these files: they are not in `prepare_model.py`'s `WDI` or `SG` download lists, and nothing reads `ext_data/reference/`.

- `wdi/ny_gdp_pcap_cd.csv`: World Bank World Development Indicators via Gapminder's open-numbers mirror (github.com/open-numbers/ddf--open_numbers--world_development_indicators), `NY.GDP.PCAP.CD`, GDP per person, current US$; added 2026-10-07.
- `wdi/sh_dth_comm_zs.csv`: World Bank World Development Indicators via Gapminder's open-numbers mirror (github.com/open-numbers/ddf--open_numbers--world_development_indicators), `SH.DTH.COMM.ZS`, deaths from communicable diseases and maternal, prenatal and nutrition conditions, % of all deaths; added 2026-10-07.
- `wdi/sh_dth_imrt.csv`: World Bank World Development Indicators via Gapminder's open-numbers mirror (github.com/open-numbers/ddf--open_numbers--world_development_indicators), `SH.DTH.IMRT`, number of infant deaths; added 2026-10-07.
- `wdi/sh_dyn_nmrt.csv`: World Bank World Development Indicators via Gapminder's open-numbers mirror (github.com/open-numbers/ddf--open_numbers--world_development_indicators), `SH.DYN.NMRT`, neonatal mortality rate, per 1,000 live births; added 2026-10-07.
- `wdi/sh_imm_hepb.csv`: World Bank World Development Indicators via Gapminder's open-numbers mirror (github.com/open-numbers/ddf--open_numbers--world_development_indicators), `SH.IMM.HEPB`, hepatitis B (HepB3) immunization, % of one-year-olds; added 2026-10-07.
- `wdi/sh_uhc_sci_id.csv`: World Bank World Development Indicators via Gapminder's open-numbers mirror (github.com/open-numbers/ddf--open_numbers--world_development_indicators), `SH.UHC.SCI.ID`, UHC service coverage sub-index on infectious diseases; added 2026-10-07.
- `wdi/sh_xpd_ghed_gd_zs.csv`: World Bank World Development Indicators via Gapminder's open-numbers mirror (github.com/open-numbers/ddf--open_numbers--world_development_indicators), `SH.XPD.GHED.GD.ZS`, domestic general government health expenditure, % of GDP; added 2026-10-07.
- `sg/ddf--datapoints--all_forms_of_tb_treatment_coverage_percent--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `all_forms_of_tb_treatment_coverage_percent`, TB treatment coverage, all forms, %; added 2026-10-07.
- `sg/ddf--datapoints--annual_hiv_deaths_number_all_ages--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `annual_hiv_deaths_number_all_ages`, HIV deaths per year, all ages; added 2026-10-07.
- `sg/ddf--datapoints--hiv_deaths_in_children_1_59_months_total_deaths--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `hiv_deaths_in_children_1_59_months_total_deaths`, HIV deaths in children aged 1-59 months; added 2026-10-07.
- `sg/ddf--datapoints--malaria_number_of_cases_reported--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `malaria_number_of_cases_reported`, reported malaria cases; added 2026-10-07.
- `sg/ddf--datapoints--malaria_number_of_deaths_reported--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `malaria_number_of_deaths_reported`, reported malaria deaths; added 2026-10-07.
- `sg/ddf--datapoints--meningitis_deaths_in_children_1_59_months_total_deaths--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `meningitis_deaths_in_children_1_59_months_total_deaths`, meningitis deaths in children aged 1-59 months; added 2026-10-07.
- `sg/ddf--datapoints--newly_hiv_infected_number_all_ages--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `newly_hiv_infected_number_all_ages`, new HIV infections, all ages; added 2026-10-07.
- `sg/ddf--datapoints--number_of_child_deaths--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `number_of_child_deaths`, deaths of children under 5; added 2026-10-07.
- `sg/ddf--datapoints--pertussis_deaths_in_children_1_59_months_total_deaths--by--geo--time.csv`: Gapminder Systema Globalis (github.com/open-numbers/ddf--gapminder--systema_globalis; WHO / UNAIDS / IHME estimates), `pertussis_deaths_in_children_1_59_months_total_deaths`, pertussis deaths in children aged 1-59 months; added 2026-10-07.
